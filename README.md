# m_and_e_react_native
Morning and Evening Devotional React Native App

This app displays the daily readings from Charles Spurgeon's Morning and Evening.

Built with [Expo](https://expo.dev) (React Native + TypeScript). This project was
converted from a Vue 3 PWA; devotional content lives in `src/data/content.json`.

### Development

```
npm install
npm run ios      # or: npm run android / npm run web
```
